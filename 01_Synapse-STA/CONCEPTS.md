## 세션 0 (2026-10-29)

| 개념 | 비유 | 이 실험에서의 역할 | 예측과 실제 결과 |
| --- | --- | --- | --- |
| 평균으로 잡음 줄이기 (STA) | 시끄러운 경기장에서 같은 말을 여러 번 녹음해 겹치면 목소리만 남는다 | 출발 스파이크마다 도착 신호를 잘라 평균 → 연결이 있으면 일정한 굴곡이 남고, 없으면 평평 | 예측: 잡음이 10배일 때 N=10,000은 있어야 보임 → 실제: N=100에서 흐릿하게, N=1,000이면 뚜렷 |
| 잡음은 1/√N로 준다 | 술 취한 사람이 100걸음 걸어도 출발점에서 약 10걸음만 멀어진다 (무작위는 서로 상쇄) | 필요한 스파이크 수를 가늠하는 기준. 잡음을 절반으로 줄이려면 4배, 1/10로 줄이려면 100배 필요 | 예측: N 4배 → 잡음 1/4 → 실제: 1/2 (10 → 3.16 → 1 → 0.32 → 0.1) |
| 원신호 한 번으로는 판정 불가 | 한 번 들은 소리로 누가 말했는지 확신하지 못한다 | Fig4d EPSP 쌍: 5초 동안 출발 스파이크 8번. 확대한 한 번은 EPSP가 보였지만, 8번 중 몇 번은 반응이 음수로 나옴 | 예측: 5초에 약 50번, 평균 없이는 안 보임 → 실제: 8번(약 1.6Hz). 가장 큰 스파이크 하나에선 보였지만 나머지 대부분은 잡음에 묻힘 |
| 가능한 연결 쌍의 수 | A→B와 B→A는 다른 길(일방통행), 자기 자신은 제외 | 거짓양성률의 분모 후보. 4,096 × 4,095 ≈ 1,677만 쌍 중 71,127개(약 0.4%)가 연결 판정 | [내 아이디어] 처음 설명의 4,096×4,096을 4,096×4,095로 바로잡음 |
| 신호 대 잡음비 (S/N) | 친구 목소리가 경기장 소음보다 몇 배 큰가 | 신호 높이 ÷ 남은 잡음(0.079/√N). 단위가 달라도 비교 가능. Fig4d EPSP: 0.15 ÷ (0.079/√8) ≈ 5배 | 처음엔 표가 어려웠음 → `session0/snr_explained.py` 그림(회색 띠 = 잡음, 빨간 화살표 = 신호)으로 이해 |
| 스파이크 수 = N | 녹음을 몇 번 겹치느냐 | 시트별 스파이크 수(AP 15, AP+EPSP 28, EPSP 8, IPSP 45)로 평균 후 잡음을 미리 계산 | — |

## 세션 2 · M1 (2026-10-30)

| 개념 | 비유 | 이 실험에서의 역할 | 예측과 실제 결과 |
| --- | --- | --- | --- |
| 샘플 | 초고속 카메라의 프레임 한 장 (1초에 9,415장) | 샘플 1개 ≈ 0.106ms. STA 창 705샘플 = 스파이크 전 25ms + 후 50ms (논문 Methods). 235번 샘플 = 출발 스파이크 순간 | 사용자 기억: "전후 각각 75ms" → 실제: 창 **전체**가 75ms |
| AP / EPSP / IPSP | 컵에 차는 물. EPSP = 물을 조금 부음, IPSP = 조금 퍼 감, AP = 선을 넘으면 확 쏟아짐 | AP만 다음 뉴런으로 전해진다(말하기). EPSP·IPSP는 받는 뉴런 안에서만 오르내린다(들은 말에 마음이 기움) | — |
| 억제성 연결 | 회의에서 반대표. 아무 표도 안 온 것과 다르다 | 받는 뉴런이 AP를 내기 어렵게 만드는 브레이크. 없으면 흥분이 번져 폭주(발작) | — |
| 4가지 템플릿의 뜻 | 몽타주 4장 | 사용자 정리: EPSP = 약한 흥분성 연결(A 혼자서는 B를 넘치게 못 함), IPSP = 억제성, AP+EPSP = B가 A를 따라 자주 AP까지 내는 강한 흥분성, **AP = A와 거의 동시라 화학 시냅스로는 불가능 → 전기 시냅스 또는 같은 세포가 두 전극에 걸림. 그래서 지연이 없다** | — |
| 템플릿 = 세 토막 | 레시피(함수)와 재료 양(pre, rise, τ) | 평평(pre) + 오름(rise) + 감쇠(나머지 칸 전부, τ는 가라앉는 속도). IPSP = 1 − EPSP | 예측: EPSP 최대 345번째, IPSP 최소 같은 자리·값 0 → 실제: 344번(0부터 셈), 0.0000. **근거 맞음** |
| 템플릿 이동(정렬) | 투명 필름을 STA 꼭대기로 밀어서 겹쳐 보기 | 연결마다 지연이 달라서 필요. 가짜 STA 예시에서 고정 0.86 → 이동 0.99. **AP만 이동 안 함**(정의가 "동시"). 흔한 실패: 잡음이 크면 꼭대기를 잘못 잡음(385 → 361) | — |
| 그림과 코드의 불일치 | 같은 레시피에 다른 재료 양 | AP 템플릿: 판정 코드 (35, 200, 100) → 0ms, Fig4a (150, 120, 80) → +3.6ms. [내 아이디어] 둘 중 하나는 틀렸다 → M2에서 두 템플릿으로 각각 판정해 Fig4g와 비교하면 가릴 수 있다 | 결과: 3개 일치, AP 불일치. 실험의 첫 "틈" 후보 |

## 열린 질문

- 거짓양성률 5.7%의 분모는 무엇인가? 1,677만 쌍 전체라면 거짓 연결만 약 95만 개 → 실제 71,127개와 안 맞음. M4에서 논문 코드로 확인.
- 전극 하나 = 뉴런 하나인가? 픽셀 간격 20μm라 뉴런 하나가 픽셀 여러 개에 걸리거나 빈 픽셀이 있을 수 있음. 논문 연결은 픽셀 단위. 이웃 픽셀끼리의 지연 0 "AP 연결" 중 일부가 같은 세포일 가능성은? (M2~M3에서 거리별로 확인해 볼 수 있음)
- [내 아이디어] STA 4종 분류에 AI를 쓰면? → 정답 라벨이 없음(템플릿 매칭 결과로 학습시키면 템플릿 매칭 흉내만 냄). 대안: 라벨 없이 STA를 군집화해서 4종류 외의 모양이 있는지 보기. 실험 1 이후 확장 후보.
- AP 템플릿: 실제 판정에 쓴 건 코드 값(0ms)인가 그림 값(+3.6ms)인가? M2에서 Fig4g와 비교해 판가름.
